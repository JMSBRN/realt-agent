# Realt Agent

Пишете боту в Telegram «однушка в Минске до $40 000, не первый этаж». Расширение в **вашем** Chrome открывает realt.by, листает выдачу как человек, и через полминуты бот присылает подходящие квартиры: фото, цену, адрес и ссылку.

Эта ветка (`main`) работает **без облачных сервисов**: один Node-сервер на вашем компьютере или VPS. Многопользовательская версия на Next.js + Supabase лежит в ветке [`supabase-version`](../../tree/supabase-version).

```
Telegram ◀─long polling─▶ apps/server (Node): диалог «как у риелтора»
                              │  SQLite: запросы, «уже видел», подписки
                              │
                         WebSocket (токен)
                              │
                              ▼
                  Chrome-расширение: открывает realt.by,
                  читает __NEXT_DATA__, возвращает объявления
```

## Структура

| Путь | Что внутри |
|---|---|
| `apps/server` | Telegram-бот (grammY), диалог с клиентом (`dialogue.ts`), разбор фраз на правилах (`extract.ts`), SQLite (встроенный `node:sqlite`), WebSocket для расширения, подписки |
| `apps/extension` | Chrome-расширение (WXT, MV3): подключается к серверу, ищет на realt.by |
| `packages/shared` | Общие типы и zod-схемы, протокол сервер ↔ расширение, адаптер realt.by (URL, разбор, фильтр) |

## Как это работает

1. Бот ведёт диалог как риелтор. На старте клиент выбирает режим:
   - **⚡ Быстрый поиск** — купить или снять, комнаты, бюджет, площадь, этаж, район → сразу варианты;
   - **🤝 Подробный подбор** — те же вопросы, плюс анкета риелтора (`apps/server/src/survey.ts`): для чего жильё, кто будет жить, дети и школа/садик, животные, что важно рядом, ремонт, тип дома, дом и соседи, сроки, оплата или срок аренды, пожелания. Затем — контакты: согласие на обработку данных, имя, телефон (кнопка «📱 Поделиться номером»), email, мессенджер, удобное время звонка. Заявка становится **лидом**, и бот сразу показывает варианты.

   У каждого вопроса есть кнопки, но можно отвечать своими словами.
   - Можно сразу одной фразой («куплю двушку от 60 до 80 тыс $»): бот возьмёт из неё всё, что понял, и спросит только недостающее.
   - **Если известна вилка бюджета** (от и до), бот ищет сразу, без оставшихся вопросов.
   - После выдачи бот предлагает изменить бюджет или комнаты, следить за новыми, начать заново или **«📞 Связаться с риелтором»** (сбор контактов → лид). Если в бюджете ничего нет, называет самый доступный подходящий вариант и предлагает поднять потолок.
   - «А до 120 тысяч?» после выдачи уточняет прошлый поиск.
2. Сервер сохраняет запрос и передаёт задачу расширению по WebSocket. Если браузер не в сети, задача ждёт до 30 минут.
3. Расширение открывает realt.by в фоновой вкладке (паузы, прокрутка, 1–3 страницы) и берёт объявления из `__NEXT_DATA__`.
4. Сервер фильтрует результат, отмечает показанное и присылает карточки с фото или список ссылок.
5. `/watch` включает подписку: раз в `WATCH_INTERVAL_MIN` минут бот присылает только новые объявления.
6. **Лиды** сохраняются в SQLite, уходят строкой в Google Sheets (колонка «Статус» — для работы риелтора) и уведомлением риелторам в Telegram. Если Google недоступен, лид досылается позже.

Команды бота: `/new` (новый поиск), `/watch`, `/stop`, `/format` (фото или ссылки), `/limit 5`, `/status`, `/help`.

## Запуск

Нужны **Node.js 22.13+** и **pnpm**.

```bash
pnpm install
```

### 1. Сервер
1. Создайте бота у @BotFather.
2. Настройте и запустите:
   ```bash
   cp apps/server/.env.example apps/server/.env   # заполнить
   pnpm --filter @realt-agent/server start
   ```
   В `ALLOWED_TELEGRAM_IDS` укажите свой Telegram id. Если не знаете его, напишите боту: он ответит вашим id.

### 2. Расширение
```bash
pnpm --filter @realt-agent/extension build
```
1. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `apps/extension/.output/chrome-mv3`.
2. В окне расширения укажите адрес сервера (`ws://127.0.0.1:8765`) и токен (`WS_TOKEN` из `.env`). На иконке появится **ON**.

### Сервер на VPS
- Поставьте `WS_HOST=0.0.0.0`.
- Не открывайте `ws://` в интернет без шифрования: поставьте перед сервером nginx или Caddy с HTTPS, а в расширении указывайте `wss://ваш-домен`.
- Сервер держите под systemd или pm2.

### Google Sheets (лиды)

1. Откройте [console.cloud.google.com](https://console.cloud.google.com), создайте проект.
2. **APIs & Services → Library** → найдите **Google Sheets API** → **Enable**.
3. **IAM & Admin → Service Accounts → Create service account**: любое имя → **Done**.
4. Откройте созданный аккаунт → **Keys → Add key → Create new key → JSON**. Скачается файл-ключ.
5. Загрузите ключ на сервер (с компьютера, в PowerShell):
   ```powershell
   scp $HOME\Downloads\имя-ключа.json root@<IP>:/root/realt-agent/apps/server/google-key.json
   ```
6. Создайте Google-таблицу → **Настройки доступа** → добавьте адрес `client_email` из ключа (`…@….iam.gserviceaccount.com`) с правами **Редактор**.
7. В `apps/server/.env`:
   ```
   GOOGLE_SERVICE_ACCOUNT_FILE=/root/realt-agent/apps/server/google-key.json
   GOOGLE_SHEET=https://docs.google.com/spreadsheets/d/…   # ссылка на таблицу
   ```
8. `systemctl restart realt-agent`. Первый лид создаст строку заголовков.

Уведомления риелтору: впишите его Telegram id в `REALTOR_CHAT_IDS` (узнать — у @userinfobot). Риелтор должен один раз нажать **Start** у бота: боты не могут писать первыми.


## Ограничения и что дальше

- **Только Минск.** Другие города добавляются в `REALT_TOWNS` (`packages/shared/src/realt.ts`): townUuid берётся из параметра `addressV2` в адресе страницы realt.by.
- **Фильтры комнат и цены применяются у нас**, после загрузки страниц выдачи. Их стоит перенести в URL самого realt.by.
- Один сервер обслуживает один браузер. Для многих пользователей — ветка `supabase-version`.
